# Limitaciones — Fase 21 (Lisboa360)

## 1. Limitaciones técnicas

- El CRS de Lisboa aún requiere confirmación autoritativa (reproyección basada en WKT).
- El tipo de geometría del GeoJSON de Suba es inconsistente (MultiPolygon vs Polygon).
- El dataset IDPC está excluido por inconsistencia de CRS.

## 2. Limitaciones de datos

- El dataset IDRD tiene cobertura distrital y puede no incluir todas las pistas/escenarios existentes.
- La ausencia de registros no implica ausencia de infraestructura.
- Sin datos demográficos compatibles: no se calcularon densidades per cápita.
- Sin red vial verificable: no se realizó análisis de accesibilidad.

## 3. Limitaciones de interpretación

- Los resultados describen Lisboa, no Suba ni Bogotá.
- No se generaron métricas de cobertura poblacional.
